# VG Web Prototype

Static Next.js prototype — no CMS, no backend. See PROJECT_CONTEXT.md for full architecture context.

## Setup

```bash
npm install
npm run dev
```

## Branching

- main is protected — PR + review required to merge
- branch per hub: feature/<hub-name> (e.g. feature/home, feature/about)
- do not modify /components/layout, /components/sections, or /lib/types without raising it with the team first
